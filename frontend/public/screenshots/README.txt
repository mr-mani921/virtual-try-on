PWA Screenshots
===============

To complete the PWA setup, add screenshots:

1. desktop-1.png (1920x1080) - Desktop view of the app
2. mobile-1.png (750x1334) - Mobile view of the app

These screenshots are displayed when users are prompted to install the app.

Best practices:
- Show the main features and UI
- Use actual app content, not placeholder text
- Keep images under 1MB for faster loading
- Use PNG format for best quality

You can capture screenshots:
1. Using browser DevTools device emulation
2. From actual devices
3. Using screenshot tools like Snipping Tool, Greenshot, etc.
